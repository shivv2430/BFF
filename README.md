# BFF — Build For a Friend 💛

> *"Pick one real person and build something for them. It doesn't have to be big. It has to matter to them."*

A simple, cozy web app designed to inspire and track micro-projects built with care for an **audience of one**.

🔗 **Live Demo:** [https://shivv2430.github.io/BFF/](https://shivv2430.github.io/BFF/)  
📦 **GitHub Repository:** [https://github.com/shivv2430/BFF](https://github.com/shivv2430/BFF)

---

## 🌟 About The Project

Most coding projects try to reach thousands or millions of users. **BFF (Build For a Friend)** flips that script:

- **Audience of One**: Build for your roommate, your grandpa, your partner, your sibling, or your best friend.
- **Micro Over Massive**: It can be built in an afternoon or a weekend. A single helpful button or thoughtful feature is better than an overwhelming dashboard.
- **Gift Culture**: Treat software like a handmade birthday card or baked cookies. Send the link in a text message and see their face light up.

## 💡 The 3 Starter Ideas (Included as Interactive Demos)

This site comes with working interactive demos for each of the core prompt ideas:

### 1. 🥗 Roommate's Allergy Meal Planner
* **Built for**: Alex (Roommate with severe peanut and gluten sensitivities).
* **What it does**: Live checklist where you toggle active allergies (Peanuts, Gluten, Dairy), and it instantly filters safe recipes so you never have to spend 45 minutes debating what to eat.
* **Interactive Features**:
  - Live allergen filter
  - "Surprise Alex Tonight" randomized safe meal picker

### 2. 🗣️ Patient Practice Partner
* **Built for**: Mateo (A friend learning Spanish before moving to Madrid).
* **What it does**: A friendly, zero-pressure conversational partner to practice everyday phrases (e.g., ordering a coffee at a café).
* **Interactive Features**:
  - Click-to-say phrase buttons
  - Free-form Spanish text input
  - Patient barista responses with instant English translations
  - Supportive coach notes that celebrate making mistakes and trying

### 3. 🎙️ Grandpa's Voice Memo Recipe Book
* **Built for**: Grandpa Joe (84-year-old grandfather who shares family recipes through rambling voice notes).
* **What it does**: Turns long WhatsApp audio stories into clean, structured family heirloom recipe cards preserving his cooking secrets.
* **Interactive Features**:
  - Play/Pause simulated voice memo player
  - Live transcript playback
  - Keepsake recipe card with Grandpa's golden rules and a 1-click "Copy Recipe" button

## 🚀 How to Run Locally

This project uses standard, pure web technologies (**Vanilla HTML5, CSS3, and JavaScript**). There are no complicated frameworks, node modules, or build steps required.

### Option 1: Open Directly in Your Browser
Double-click `index.html` in your file explorer (Finder on macOS) to open it directly in Chrome, Safari, or Firefox.

### Option 2: Run with a Local Server
Using Python:
```bash
# In the project directory:
python3 -m http.server 8080
```
Then visit: [http://localhost:8080](http://localhost:8080)

Using Node:
```bash
# Using npx serve:
npx serve .
```

## 📜 The Three Golden Rules

1. **The Audience of One**: If it solves a real frustration for one person you love, it is a 100% success.
2. **Keep It Micro**: Scope it down until you can ship it in an afternoon.
3. **The Personal Touch**: An inside joke or thoughtful Easter egg turns code into a digital keepsake.
